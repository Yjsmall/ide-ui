# ZCode IDE UI

A modern macOS-style dark theme IDE interface featuring:

- **Minimalist macOS Controls**: Fixed top-left toolbar with sidebar toggle, navigation buttons, and responsive layouts.
- **Collapsible Sidebar**: Embedded sidebar that smoothly expands and collapses with bezier transitions.
- **Floating Window Canvas**: Elevated rounded floating card with drop shadow and border lighting that expands to full width when the sidebar collapses.
- **Project Folder Management**: Upload local directories via directory picker or drag-and-drop, and inline double-click folder renaming with localStorage persistence.

## Getting Started

Simply open `index.html` in any modern web browser:

```bash
open index.html
```

Or start a local preview server:

```bash
python3 -m http.server 8080
```
